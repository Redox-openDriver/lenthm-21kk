# Безопасность

## Linux
`lenthmd` работает от имени пользователя, без root: он читает датчики из `/sys/class/hwmon` и `/sys/class/thermal`,
ведёт дневник охлаждения в `~/.local/state/lenthm` и пишет предупреждения в журнал. Вентилятором, порогами и защитой
от перегрева по-прежнему занимаются прошивка и ядро: драйвер ничего не переключает. Установщик не просит root и
ставит программы в `~/.local/bin`.

## Redox
`lenthmd` отображает окно памяти контроллера (`0xFE802000`) только на чтение и не пишет ни в него, ни в порты
контроллера.

## Как сообщить об уязвимости
Через закрытое сообщение об уязвимости на странице репозитория в GitHub (Security → Report a vulnerability), не в
открытом обсуждении.
